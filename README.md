# TUNE TOTS — Music Laboratory

Это полностью статический сайт: HTML + CSS + JS + изображения.
Никакого платного конструктора и никакой базы данных для текущей версии не требуется.

## Самый быстрый бесплатный запуск

### Вариант 1 — GitHub Pages
1. Создай бесплатный аккаунт на GitHub.
2. Создай новый публичный репозиторий, например `tune-tots-site`.
3. Загрузи в него все файлы из этой папки.
4. Открой **Settings → Pages**.
5. В Source выбери **Deploy from a branch**, ветку `main`, папку `/root`.
6. GitHub даст бесплатный адрес сайта.

### Редактирование
Тексты находятся прямо в `index.html`. Можно открыть файл на GitHub и нажать Edit.
Цвета, размеры, сетка и анимации находятся в `styles.css`.
